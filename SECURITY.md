# Security

Report vulnerabilities privately to the maintainers (open a private security advisory on the repository).
Do not file public issues for them. Include the version, a minimal file or command that reproduces it, and
the impact. We aim to answer within 7 days.

Areas that matter most: file import (`.fig`, `.sketch`, `.figcraft`, SVG), the control channel and its
token, the MCP server, plugins (WASM sandbox) and path handling for automation roots.
